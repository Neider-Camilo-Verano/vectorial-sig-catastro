Conectando con la base de datos…

El visor necesita el servidor y la base de datos

  1. Verifica que PostgreSQL esté encendido y que la base ya esté cargada (README, sección 5).
  2. En la carpeta del proyecto haz doble clic en iniciar.bat (Windows) o ejecuta ./iniciar.sh.
  3. Abre http://127.0.0.1:8000 en el navegador. No abras index.html con doble clic ni lo subas a un hosting estático (Netlify, GitHub Pages): ahí no existe la API.

Consultar un predio

Haz clic sobre el mapa. La API busca en PostGIS el terreno que contiene ese punto (ST_Intersects) y devuelve su ficha con las construcciones.
