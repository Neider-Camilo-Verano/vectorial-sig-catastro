# Evidencias técnicas

Guarde aquí, después de ejecutar el proyecto en su equipo:

1. `verificacion.txt` — salida de `python scripts/verificar_api_vs_sql.py` (API vs SQL).
2. `01_interfaz.png` — visor con las capas activas.
3. `02_api_json.png` — respuesta de un endpoint (por ejemplo `/api/terrenos/en-punto?lat=4.52896&lng=-75.64182`) en el navegador.
4. `03_sql_pgadmin.png` — la consulta equivalente ejecutada directamente en pgAdmin (bloque 3 de `db/03_consultas_verificacion.sql`).
5. `04_explain.png` — `EXPLAIN ANALYZE` del bloque 5 mostrando el índice `terreno_geom_gix`.
